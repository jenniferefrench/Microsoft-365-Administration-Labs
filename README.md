# Microsoft 365 Administration Labs

Hands-on administration labs using Microsoft 365 Business Premium, Microsoft Teams Admin Center, Microsoft Entra ID, and Microsoft Intune.

## Overview

I created a Microsoft 365 test environment to practice common IT help desk and administrator tasks, including user account management, group membership, access controls, Teams administration, identity management, and endpoint compliance policies.

These labs focus on practical skills used when supporting employees in a business environment.

## Technologies Used

- Microsoft 365 Admin Center
- Microsoft Teams Admin Center
- Microsoft Entra ID
- Microsoft Intune
- Microsoft 365 Business Premium

## Lab 1 — Microsoft 365 User Administration

Created a test employee account in Microsoft 365 Admin Center.

Tasks completed:
- Created a standard user account without administrative privileges
- Reviewed account properties and licensing
- Practiced resetting the user's password
- Blocked and restored user sign-in
- Reviewed license assignment options

## Lab 2 — Microsoft 365 Group Management

Created an IT Support Team Microsoft 365 group and managed its membership.

Tasks completed:
- Created a Microsoft 365 group
- Assigned a group owner
- Added a test employee as a member
- Practiced removing and re-adding a group member

![Group Creation](screenshots/03-M365-Group-Creation.png)

## Lab 3 — Microsoft Teams Administration

Explored administrative settings used to manage collaboration and communication.

Areas reviewed:
- Team settings and permissions
- Team privacy
- Guest permissions
- Messaging settings
- Meeting policies
- Organization-wide default policies

![Teams Meeting Policies](screenshots/04-Teams-Admin-Meeting-Policies.png)

## Lab 4 — Microsoft Entra ID

Explored identity and access management in Microsoft Entra ID.

Tasks completed:
- Located and reviewed a user identity
- Verified administrative role assignments
- Reviewed group memberships
- Examined the sign-in logs interface
- Reviewed user access information

![Entra ID Group Membership](screenshots/05-Entra-ID-Group-Membership.png)

## Lab 5 — Microsoft Intune Device Management

Explored Microsoft Intune device enrollment and compliance administration.

Tasks completed:
- Reviewed enrolled device inventory
- Examined Windows enrollment settings
- Reviewed device platform enrollment restrictions
- Created a Windows compliance policy
- Configured requirements for BitLocker and Secure Boot
- Reviewed noncompliance actions
- Left the policy unassigned to avoid affecting devices
- Reviewed device compliance monitoring

The lab did not include enrolling a physical device or testing actual device compliance.

![Intune Compliance Policy](screenshots/06-Intune-Compliance-Policy.png)

## Skills Practiced

Microsoft 365 Administration | User Account Management | Password Resets | Access Management | Microsoft Entra ID | Group Management | Microsoft Teams Administration | Microsoft Intune | Device Compliance Policies | IT Help Desk Support

## Key Takeaways

These labs helped me become more familiar with Microsoft cloud administration tools and the workflows involved in supporting employees, managing access, troubleshooting account issues, and reviewing endpoint security requirements.

The environment was used for hands-on learning without affecting production users or devices.
